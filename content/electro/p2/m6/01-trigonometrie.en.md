The filters in this module are calculated with two tools from right-angled triangles: **Pythagoras' theorem** and the **tangent**. No other maths is needed: a calculator with √ and tan⁻¹ (or atan) keys is enough.

![Right-angled triangle with sides a = 4, b = 3 and c = 5, and the angle θ between a and c](/static/content/electro/en/m6/triangle.svg)

## Pythagoras' theorem

In a right-angled triangle, the longest side, opposite the right angle, is the **hypotenuse** c. The other two sides a and b are linked by:

**c² = a² + b²**   so   **c = √(a² + b²)**

Example: a = 4 and b = 3. c = √(16 + 9) = √25 = **5**. Careful: c is **not** a + b = 7. That is the most common mistake.

## Tangent and angle

The angle θ, between a and the hypotenuse, is found from the ratio of the two sides around the right angle:

**tan θ = b / a**   so   **θ = arctan(b / a)**

With a = 4 and b = 3: b / a = 0.75 and θ = arctan 0.75 ≈ **36.9°**. Check that your calculator is set to **degrees** (DEG), not radians.

![Curve of θ = arctan(b / a): 30° for 0.577, 45° when b = a, then the angle approaches 90° without reaching it](/static/content/electro/en/m6/arctan.svg)

## Useful landmarks

- b = a: θ = **45°**.
- b smaller than a: θ is below 45°; b larger than a: θ is above 45°.
- b / a = 0.577: θ ≈ 30°; b / a = 1.732: θ ≈ 60°.

## Key points

- c = √(a² + b²), never a + b.
- θ = arctan(b / a), calculator in degrees.
- b = a gives 45°.
