Les filtres de ce module se calculent avec deux outils de géométrie du triangle rectangle : le **théorème de Pythagore** et la **tangente**. Pas besoin d'autre mathématique : une calculatrice avec les touches √ et tan⁻¹ (ou atan) suffit.

![Triangle rectangle de côtés a = 4, b = 3 et c = 5, avec l'angle θ entre a et c](/static/content/electro/m6/triangle.svg)

## Le théorème de Pythagore

Dans un triangle rectangle, le côté le plus long, face à l'angle droit, s'appelle l'**hypoténuse** c. Les deux autres côtés a et b sont liés par :

**c² = a² + b²**   donc   **c = √(a² + b²)**

Exemple : a = 4 et b = 3. c = √(16 + 9) = √25 = **5**. Attention : c n'est **pas** a + b = 7. C'est l'erreur la plus fréquente.

## La tangente et l'angle

L'angle θ, situé entre a et l'hypoténuse, se calcule à partir du rapport des deux côtés de l'angle droit :

**tan θ = b / a**   donc   **θ = arctan(b / a)**

Avec a = 4 et b = 3 : b / a = 0,75 et θ = arctan 0,75 ≈ **36,9°**. Vérifiez que votre calculatrice est réglée en **degrés** (DEG) et non en radians.

![Courbe de θ = arctan(b / a) : 30° pour 0,577, 45° quand b = a, puis l'angle s'approche de 90° sans l'atteindre](/static/content/electro/m6/arctan.svg)

## Quelques repères

- b = a : θ = **45°**.
- b plus petit que a : θ est inférieur à 45° ; b plus grand que a : θ est supérieur à 45°.
- b / a = 0,577 : θ ≈ 30° ; b / a = 1,732 : θ ≈ 60°.

## À retenir

- c = √(a² + b²), jamais a + b.
- θ = arctan(b / a), calculatrice en degrés.
- b = a donne 45°.
